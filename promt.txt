2. IMPORTANT RESOURCE ARCHITECTURE
============================================================

The Render backend is intended to run on a Render Free instance with approximately 512 MB RAM.

Therefore:

RENDER MUST NOT RUN:

- Chrome
- Chromium
- ChromeDriver
- Selenium browser sessions
- browser-use browser sessions
- local LLM inference
- local AI model weights
- GPU workloads

All browser execution must happen on the user's Windows machine.

Render should perform:

- FastAPI
- API handling
- AI orchestration
- Groq API requests
- task management
- WebSocket/WSS communication
- authentication
- lightweight state
- database operations
- JSON processing

The Windows Client performs:

- Chrome
- ChromeDriver
- Selenium
- browser-use
- browser sessions
- screenshots
- browser preview
- browser tasks
- local Web UI
- file handling
- communication with Render

This separation is critical.

============================================================
3. FIVE GROQ AI AGENTS
============================================================

Create five logical AI agents.

The roles should be:

AGENT 1:
PLANNER / ARCHITECT

Responsibilities:

- understand the user's request
- decompose complex tasks
- create a plan
- identify required tools
- decide whether browser automation is needed
- decide whether file analysis is needed
- delegate work

AGENT 2:
RESEARCHER / ANALYST

Responsibilities:

- analyze information
- research available information through approved tools
- analyze browser results
- analyze files
- identify relevant facts
- identify missing information
- provide evidence

AGENT 3:
SOLVER / EXECUTOR

Responsibilities:

- solve the task
- generate solutions
- execute reasoning steps
- generate browser task plans
- use available tools
- transform information into actionable operations

AGENT 4:
CRITIC / VERIFIER

Responsibilities:

- inspect proposed results
- identify errors
- challenge assumptions
- verify important information
- detect contradictions
- request additional work if necessary

AGENT 5:
JUDGE / SYNTHESIZER

Responsibilities:

- evaluate the outputs of all agents
- resolve disagreements
- determine the best result
- decide whether another deliberation round is necessary
- generate the final coherent answer
